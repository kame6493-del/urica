# コンテンツのレーティング(IARC 質問票)の回答案

- カテゴリ: 「その他のアプリ(ユーティリティ・生産性・コミュニケーション以外)」
- 暴力・流血: なし
- 性的な内容・ヌード: なし
- 汚い言葉: なし
- 薬物・アルコール・タバコ: 規制薬物・違法薬物の内容は無い。処方された薬の服用記録と、利用者が自分の飲酒量を記録する機能がある(飲酒を勧める・美化する表現は無く、休肝日を数える)。質問が「アルコールへの言及」を問う場合は「はい(記録のみ)」と答える
- ギャンブル: なし
- ユーザー同士のやり取り・コンテンツの共有: なし(自分の記録を書き出す機能はあるが、ユーザー間の交流は無い)
- 位置情報の共有: なし
- デジタル商品の購入: あり(アプリ内課金: 買い切り1つ)
- 想定される結果: 12歳以上前後(アルコールへの言及の扱いによる)/ ストアの対象年齢設定は 18歳以上を選ぶ

## 対象ユーザーとコンテンツ(Play Console 別画面)
- 対象年齢: 18歳以上
- 子ども向けの内容に見えるか: いいえ

## 健康アプリの申告(Play Console「健康アプリ」)
- 該当する機能: 服薬の管理・リマインダー、病気の記録(検査値・痛風発作)、栄養(プリン体の記録。量は利用者が入れる)
- 医療機器としての承認: なし。診断・治療・飲み方の判断は行わない「記録とお知らせ」のアプリとして申告する。

## 権限の説明(Play Console で聞かれた場合)
- POST_NOTIFICATIONS: お薬の時刻・検査日の前日のお知らせ(端末内で予約するローカル通知)
- SCHEDULE_EXACT_ALARM / RECEIVE_BOOT_COMPLETED: 通知の部品(@capacitor/local-notifications)が付ける。決まった時刻のお知らせと、再起動後に予約を戻すため
